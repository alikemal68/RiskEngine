# RiskEngine
Python-based market risk engine for portfolio Value at Risk (VaR) and Expected Shortfall (ES) estimation, incorporating EWMA, GARCH, and asymmetric GJR-GARCH volatility models with Normal, Student-t, and skewed Student-t innovations. Implemented rolling out-of-sample VaR forecasts and assessed their accuracy through Kupiec and Christoffersen statistical tests.
